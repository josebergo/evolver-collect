# Modbus 地址规则：40001 到底是什么

Modbus 的地址表达方式堪称"方言重灾区"，这一节把常见写法一次讲清。

## 经典 5 位表示法（1 基）

首数字代表数据区，后 4 位是**从 1 开始**的编号：

| 地址 | 数据区 | 协议内实际偏移 |
|---|---|---|
| `40001` | 保持寄存器 | 0 |
| `40002` | 保持寄存器 | 1 |
| `30001` | 输入寄存器 | 0 |
| `00001` | 线圈 | 0 |
| `10001` | 离散输入 | 0 |

**`40001` ≠ 偏移 40001，而是"保持寄存器第 1 格"（偏移 0）**。这就是新手配错的第一名原因。

## 前缀表示法（0 基，本项目支持）

| 写法 | 含义 |
|---|---|
| `HR100` | 保持寄存器偏移 100 |
| `IR100` | 输入寄存器偏移 100 |
| `C100` | 线圈偏移 100 |
| `DI100` | 离散输入偏移 100 |

不受 1 万偏移限制（如 `HR12345`），适合大点表设备。

## 各家厂商的方言（对照）

| 厂商/工具 | 你在手册里看到 | 本系统写法 |
|---|---|---|
| 通用 | 40001 | `40001` |
| 施耐德/部分模块 | 4x0001 | `HR0`（4x 后 0 基） |
| 西门子网关 | 400001（6 位扩展） | `HR0` 起自行加偏移 |
| 一些国产仪表 | 寄存器地址 0x00=首地址 | `HR0` |

> 💡 **判别技巧**：读手册时先找"Modbus 地址表"有没有**偏移量+1/-1** 的说明；连上后先读一小段寄存器看数值是否像目标量级，错位 ±1 是最常见问题。

## 位拆取

想取 `40010` 寄存器的第 3 位当"电机运行"信号：地址填 `40010`、类型 `UInt16`、位序号 `3`。系统读到整个寄存器后自动拆位发布。
