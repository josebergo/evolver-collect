# 欧姆龙 FINS 入门

FINS（Factory Interface Network Service）是欧姆龙 CJ/CS/CP/NJ 系列的通信协议，TCP 端口 **9600**。

## 节点寻址

FINS 用"网络号.节点号.单元号"寻址（如 `0.1.0`）：

- 网络号 0 = 本地网络
- 节点号通常等于 PLC 的 IP 末位（如 192.168.1.5 → 节点 5）
- 单元号 0 = CPU 单元

## 内存区（存储区代码）

| 区 | 名称 | 代码 |
|---|---|---|
| CIO | 核心 IO 区 | B0 |
| W | 工作区 | B1 |
| H | 保持区 | B2 |
| D | 数据存储区 DM | 82 |
| 时钟/年月日等系统区 | — | AB 等 |

DM 区最常采集（数值），CIO/W 区多状态位。

## 地址写法（本系统）

| 写法 | 含义 |
|---|---|
| `D100` | DM100（字） |
| `D100.2` | DM100 第 2 位 |
| `CIO50` | CIO 区字 50 |
| `W10` | W 区字 10 |

## 帧结构（FINS/TCP）

TCP 上先握手（客户端发节点号告知，服务端回分配的节点号），之后每次请求-响应：

```
FINS 帧头 ICF RSV GCT DNA DA1 DA2 SNA SA1 SA2 SID
       80  00  02  00  01  00  00  FF 00 00  01
命令码 01 01 82 00 64 00 01
       ↑读存储区    ↑DM ↑偏移100 ↑1个字
```

命令 `0101` = 存储区读，`0102` = 存储区写。响应码 `0000` = 正常。

## 连接要点

1. PLC 以太网口设置里开启 FINS/TCP（保持默认"自动分配节点号"最省事）
2. 防火墙放行 9600
3. 本项目 FINS 驱动自研，握手与帧解析全部有单元测试
