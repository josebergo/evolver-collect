# 三菱 MC 协议入门

MC（MELSEC Communication）是三菱 FX/Q/L/R 系列的以太网通信协议，默认端口 **5000**。

## 软元件（地址）

| 软元件 | 说明 | 地址写法 |
|---|---|---|
| `D` | 数据寄存器（16 位） | `D100` |
| `W` | 链接寄存器 | `W100` |
| `M` | 内部继电器（位） | `M100` |
| `X` / `Y` | 输入/输出继电器 | `X0` / `Y10`（十六进制编号！） |
| `L` / `B` | 链接继电器/链接特殊继电器 | `L100` |

32 位值占 2 个连续软元件（D100、D101），浮点同理。

## 帧格式（MC Binary，3E 帧）

```
50 00                副头部（固定）
00 FF                网络号/PLC 号（默认 00 FF）
FF 03                请求目标模块号/监视定时器高位……
00                   监视定时器
01 04                命令（0104 = 成批读软元件）
00 01                软元件编号（D100）
A8 00                软元件代码（A8 = D 寄存器）
00 01                软元件点数
```

命令一览：`0104` 批读字、`0181? 位读`、`1401` 批写字、`0E01` 批写位。软元件代码是每种软元件的"暗号"（D=A8、W=B4、M=90、X=9C、Y=9D）。

## 连接要点

1. PLC 侧以太网模块开 **MC 协议**（无顺序协议/双向协议都兼容 3E 帧）
2. 端口 5000；一台 PLC 只能接受有限个 TCP 连接（模块规格有关，一般 4~8 路）
3. FX 系列（FX3U/FX5U）用 FX 特有帧格式与 Q 系略有差异——本驱动按 Q/L/R（A 兼容 3E）实现，FX5U 兼容

本项目 MC 驱动为**自研实现**（无第三方库），帧构造/解析全部有单元测试覆盖，源码即教材。
