# 什么是设备数据采集

设备数据采集（Data Acquisition，业内常叫 **数采** 或 **DAQ**）就是把工厂里设备内部的数据——温度、压力、产量、运行状态、能耗——自动读取出来，送到需要这些数据的系统里（MES、能耗平台、数据库）。

## 为什么需要专门的软件

设备的"嘴"各说各话：电表说 Modbus，西门子 PLC 说 S7，三菱说 MC，新一点的设备说 OPC UA。上层系统不可能为每种设备写一遍通信代码，所以需要一个"翻译官"：

```
设备(各种协议) ──▶ 采集网关(本项目) ──▶ MQTT/Kafka/HTTP/数据库(统一格式)
```

## 三个基本概念

| 概念 | 类比 | 说明 |
|---|---|---|
| **通道 Channel** | 一根网线/串口线 | 一个物理连接，对应一台网关下的一组设备 |
| **设备 Device** | 一台机器 | 通道下的一台物理设备，有从站号/节点地址 |
| **点位 Tag** | 一个仪表读数 | 要采集的一个具体数据项，有地址、类型、周期 |

在本系统中：新建通道 → 添加设备 → 配置点位 → 启动采集。就这么简单。

## 采集的两种方式

- **轮询（Polling）**：网关每隔 N 毫秒主动问设备"现在多少"。简单通用，绝大多数 PLC/仪表走这条路（本项目 v0.x 以轮询为主）。
- **订阅（Subscribe）**：设备有变化时主动推给网关。OPC UA 原生支持，实时性好、流量省。
