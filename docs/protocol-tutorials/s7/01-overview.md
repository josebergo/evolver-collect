# 西门子 S7：内存区与地址语法

S7 是西门子 PLC 家族（S7-200 SMART / 300 / 400 / 1200 / 1500）的通信协议，走 **ISO-on-TCP（102 端口）**。

## 内存区

| 区 | 名字 | 用途 |
|---|---|---|
| `I` | 输入 | 物理输入映像 |
| `Q` | 输出 | 物理输出映像 |
| `M` | 位存储 | 中间变量（最常被采集） |
| `DB` | 数据块 | 用户数据区（采集主战场） |
| `T/C` | 定时器/计数器 | 当前值 |

## 地址语法（本系统采用 S7 标准写法）

| 地址 | 含义 |
|---|---|
| `M100` | M 区字节 100 |
| `M100.2` | M100 的第 2 位（开关量） |
| `MW100` | M 区字（Word）从 100 开始 |
| `MD100` | M 区双字从 100 开始 |
| `DB1.DBX100.0` | DB1 内位 100.0 |
| `DB1.DBW100` | DB1 内字 |
| `DB1.DBD100` | DB1 内双字（Float 常用 DBD） |

## 连接参数

| 参数 | 说明 |
|---|---|
| IP | PLC 网口地址 |
| Rack/Slot | 机架/槽号：S7-1200/1500 常为 `0/1`（1500 需 PLC 侧开启 PUT/GET） |
| 机型 | 200SMART / 300/400 / 1200/1500（PDU 大小不同） |

## 常见坑

1. **S7-1500 默认禁止外部读取**：TIA Portal 里"保护"页勾选允许 PUT/GET
2. **DB 优化访问**：新建 DB 默认"优化"，地址不再是固定偏移——采集用的 DB 必须取消勾选"优化的块访问"，编译后地址列出现偏移
3. 数值类型：SIMATIC 里 REAL=Float（DBD），DINT=Int32
