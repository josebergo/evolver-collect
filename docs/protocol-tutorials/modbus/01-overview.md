# Modbus 全景：主从模型与数据区

Modbus 是 1979 年诞生的工业协议，因为**免费、简单、够用**，至今仍是仪表/变频器/PLC 的标配。学数采基本都从它开始。

## 主从模型（请求-响应）

- **主站**：发起方，本系统扮演主站
- **从站**：设备，从站号（unit id / slave id）区分，1~247
- 从站永远不主动说话；一个请求必有一个响应

RTU 串口（RS485）是"总线"：一根线上挂多台设备，靠从站号区分谁该应答。TCP 是"星型"：每个设备一个 IP，但报文里仍保留从站号（兼容串口服务器透传）。

## 四种数据区

| 数据区 | 读写 | 位宽 | 典型用途 | 功能码（读） |
|---|---|---|---|---|
| **线圈 Coil** | 可读写 | 1 位 | 远程开关 | 01 |
| **离散输入 Discrete Input** | 只读 | 1 位 | 按钮反馈、限位 | 02 |
| **保持寄存器 Holding Register** | 可读写 | 16 位 | 设定值、参数 | 03 |
| **输入寄存器 Input Register** | 只读 | 16 位 | 测量值（电压电流） | 04 |

记忆法：**"输入"=只读（设备说了算）；"保持"=可写（主站可设定）；"离散"=开关量只读；"线圈"=开关量可写。**

## 事务流程

```
主站 →  03 读保持寄存器  起始=0  数量=2     （读 HR0 和 HR1）
从站 →  03  字节数=4  数据=00 0A 01 02     （HR0=10, HR1=258）
```

出错时从站回 `功能码+0x80 + 异常码`（1 非法功能 / 2 非法地址 / 3 非法值 / 4 从站故障 / 6 从站忙）。本系统会把异常码翻译成中文原因显示在点位上。

## 动手实验

1. 启动自带模拟器：`dotnet run --project simulator/EvolverCollect.Simulator`
2. 建通道：驱动 Modbus / 127.0.0.1:1502
3. 建点位：`40001` Float（主轴负载）、`00001` Bool（运行状态）
4. 打开总览页看实时值变化
