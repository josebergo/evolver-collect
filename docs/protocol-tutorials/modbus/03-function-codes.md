# Modbus 功能码逐个讲

## 读类

| FC | 读什么 | 一次最多 | 响应结构 |
|---|---|---|---|
| 01 | 线圈 | 2000 位 | 字节数 + 位打包（低位在先） |
| 02 | 离散输入 | 2000 位 | 同上 |
| 03 | 保持寄存器 | 125 个 | 字节数 + 大端 16 位×N |
| 04 | 输入寄存器 | 125 个 | 同上 |

**合并读**：读 HR0 和 HR1 发两条请求太浪费。本系统的调度器会把相邻点位（间隔 ≤8）合并成一次请求，最多 125 寄存器——千级点表读次数数量级下降。

## 写类

| FC | 写什么 | 说明 |
|---|---|---|
| 05 | 单线圈 | 写 true=FF00 / false=0000 |
| 06 | 单寄存器 | 写 1 个 16 位 |
| 16(0x10) | 多寄存器 | 写连续 N 个；32 位值必须用它 |

从站回显请求的关键字段作为确认（地址+数量/值），本项目会核对回显防止张冠李戴。

## 异常响应

响应功能码 = 请求功能码 + 0x80，后跟异常码：

| 码 | 中文 | 常见原因 |
|---|---|---|
| 01 | 非法功能 | 设备不支持该 FC（老仪表只有 03/04） |
| 02 | 非法数据地址 | **点表偏移错位**（最高频问题） |
| 03 | 非法数据值 | 数量超限 |
| 04 | 从站设备故障 | 设备自身故障 |
| 06 | 从站忙 | 稍后重试 |

本系统把异常映射为该点位 `Bad` + 中文原因（如"02 非法数据地址：请核对数据区与偏移"），不会中断其他点位的采集。

## 抓包示例（TCP）

```
→ 0001 0000 0006 01 03 0000 0002      读 HR0~1，从站1
← 0001 0000 0007 01 03 04 0064 0190   HR0=100, HR1=400
```

前 6 字节是 MBAP 头（事务号/协议号/长度），之后与 RTU 的 PDU 相同。下一节拆帧结构。
