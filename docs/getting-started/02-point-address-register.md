# 点位、地址与寄存器

## 寄存器：设备的"格子间"

PLC 和仪表的内存被划分成一排排格子，每格能存一个数。常见叫法：

- **寄存器（Register）**：16 位格子，存数值（123、4567）
- **线圈（Coil）**：1 位格子，只有开/关（true/false）

数据手册里的"寄存器地址表"就是这些格子的编号清单——**数采的核心工作就是把点位的地址对应到这些格子**。

## 一个点位的完整定义

以一块电表为例：

| 字段 | 值 | 说明 |
|---|---|---|
| 名称 | `电压` | 给人看的 |
| 地址 | `40001` | 给协议看的：保持寄存器第 0 格 |
| 数据类型 | `Float` | 占 2 个格子，按浮点数解释 |
| 采集周期 | `1000ms` | 每秒读一次 |
| 换算 aX+b | `0.1` | 原始值 2210 → 221.0V |

## 数据类型与字节

- 16 位寄存器：`Int16`(-32768~32767) / `UInt16`(0~65535)
- 32 位（占 2 个寄存器）：`Int32` / `UInt32` / `Float`（带小数）
- 64 位（占 4 个寄存器）：`Int64` / `Double`
- 开关量：`Bool`；从寄存器某一位取开关 → 配"位序号（BitIndex）"

> ⚠️ **多寄存器字序陷阱**：32 位值占 2 个寄存器，先读到的可能是高位字（ABCD 标准）也可能是低位字（CDAB，部分国产设备）。现象是浮点值乱码或大得离谱——把通道参数里的"字交换序"切换试试。

## 工程量换算

设备存原始值（精度受限于整数格），人要工程量：

- 温度：寄存器存 `253`，换算 `0.1×x` → `25.3°C`
- 压力：存 `895`，换算 `0.01×x` → `8.95MPa`

公式就是 **value = a × 原始值 + b**，在点位编辑里配置。
